# BiteRush

## Online Food Delivery Platform

BiteRush is a modern, responsive food delivery web application that allows users to browse food items, search by category, add items to their cart, place orders, and manage their account.

## Features

- User registration and login
- Browse food categories
- Search food items
- Food details
- Add to cart
- Update cart quantities
- Checkout
- Order management
- User profile
- Order history
- Responsive design
- Admin food management
- Order status management
- Payment integration

## Technologies

- React
- TypeScript
- Tailwind CSS
- Supabase
- JavaScript
- HTML
- CSS
